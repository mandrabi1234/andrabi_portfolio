## Overview

A single source of truth for every Generative AI Production Technology initiative and R&D
solution at Sony Pictures, used by business users across the participating divisions.

## What I built

- An automated, centralized database that consolidates initiative data company-wide.
- Automated ingestion, including an IMDb API integration that fills in title data.

## Impact

- Data processing dropped to under 5 minutes per refresh across all participating divisions.
- Manual data entry fell by more than 80%.
