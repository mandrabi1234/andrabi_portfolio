## Overview

Sony Pictures' Post Sound team tracks talent across casting and production documents. I built an
automated system that reads those documents, structures the talent data, and matches talent to
relevant productions.

## What I built

- A Python pipeline that uses GPT to parse unstructured casting and production documents.
- An Airtable-backed database, with JavaScript automation, that the team queries directly.
